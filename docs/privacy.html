プライバシーポリシー / Privacy Policy — YouTube Watched Hider

最終更新 / Last updated: 2026-10-11

日本語 · English · 紹介ページ · Overview

日本語

本拡張機能「YouTube Watched Hider」（以下「本拡張」）は、利用者のプライバシーを最大限尊重します。

収集するデータ

本拡張は、利用者の個人情報・操作ログ等を開発者サーバーへ収集しません。保存したローカルデータを開発者サーバーや解析ツールへ送信せず、第三者提供も行いません。

ローカル保存データ

以下のデータを、ブラウザ内（IndexedDB および chrome.storage.local）にのみ保存します。

  • IndexedDB watchedVideos: 視聴した YouTube 動画の ID・タイトル・チャンネル名・視聴日時・初回視聴日時・再生回数・検出元・動画長（durationSec）・動画長取得失敗理由・作曲/作詞/編曲クレジット等
  • 上記のうちクレジット関連では、次回いつ調べ直すかの判定に使う情報（最終チェック日時・概要欄から取れなかった回数・楽曲データベース照会の再照会期限）と、「データ修復」で空欄へ戻した際の元の値を各レコード内に保存します。元の値は修復を取り消せるようにするためのもので、外部へは送信しません。
  • IndexedDB likedVideos: ユーザー操作により同期した高評価動画の ID・タイトル・チャンネル名・同期日時・プレイリスト順等
  • chrome.storage.local: 本拡張の設定値（非表示トグル、ショート/映画非表示、自動バックアップ等）、高評価同期メタ情報（likedSyncMeta）、最終バックアップ日時・件数・失敗理由（lastBackup / lastBackupCount / lastBackupError）、移行・クリーンアップ状態等

高評価同期メタ情報には Cookie や認証ヘッダは保存しません。これらのデータは利用者の端末内に保存され、本拡張は開発者または第三者のサーバーへ送信しません。

オフスクリーンドキュメントの利用

本拡張は Chrome 拡張の offscreen document 機能を使い、IndexedDB 操作と大容量 JSON バックアップ用 Blob URL の生成を拡張機能側の画面外ドキュメントで行います。これは YouTube タブを開いていない状態でも履歴ビューア・エクスポート・自動バックアップを動作させるための内部処理であり、外部送信を伴いません。

外部通信

本拡張は、機能実行に必要な範囲で YouTube 公式エンドポイントおよび楽曲データベース MusicBrainz に通信します。

  • https://www.youtube.com/oembed — 動画タイトル / チャンネル名の補完取得
  • https://www.youtube.com/watch?v=... — 埋め込み禁止動画のメタデータ取得フォールバック、作曲/作詞/編曲クレジット、動画長（lengthSeconds）の補完
  • https://www.youtube.com/playlist?list=LL および https://www.youtube.com/youtubei/v1/browse — ユーザー操作時の高評価プレイリスト同期
  • https://musicbrainz.org/ws/2/... — ユーザーが「Fix Credits」、検索フィルターの「他Topic ◯件をクレジット確認」、または保存済みクレジットの再点検で「MusicBrainzでも照合する」を選んで点検を明示的に実行したときのみ、作曲/作詞/編曲クレジット候補を補完するための照会。送信するのはアーティスト名・曲タイトル由来の検索文字列です。日本語表示での再点検では、同じ役割にローマ字名と日本語名が混在するとき、同一人物の読みを確認するため日本語の人物名だけを送る検索も行います。Cookie や YouTube 認証情報は送信せず、開発者サーバーを経由しません。

YouTubeページ上で実行される content script から YouTube 自身へ同一オリジン通信する場合、ブラウザが YouTube の Cookie または認証ヘッダを付与することがあります。これらは YouTube 以外の外部サーバー、本拡張の開発者、第三者には送信・保存されません。

データの削除

拡張機能をアンインストールすると、本拡張がブラウザ内に保存したデータは Chrome によって自動的に削除されます。ブラウザ内の視聴履歴は、拡張の「設定・データ管理 → データ削除 → 視聴履歴だけ削除」からも削除できます。ダウンロード済みの JSON バックアップは削除されないため、利用者が別途管理してください。

English

This extension ("YouTube Watched Hider") does not collect, transmit, or share personal data with the developer or any third party. Watch history, liked-video sync data, extension settings, backup status, and sync metadata are stored locally in the browser (chrome.storage.local / IndexedDB). Liked sync metadata does not store YouTube cookies or authorization headers. Credit-related records also keep the information used to decide when to look a video up again, and — when you run the credit repair under データ修復 ("Data repair") — the original values that were cleared, so that the repair can be undone; none of this is sent anywhere.

The extension uses Chrome's offscreen document feature for internal IndexedDB access and Blob URL generation for JSON export / backup. This does not transmit data externally.

External requests go to YouTube endpoints such as oembed, public watch page HTML for metadata / credits / duration backfill, playlist?list=LL, and youtubei/v1/browse, and to the MusicBrainz music database (https://musicbrainz.org/ws/2/...) — only when you run "Fix Credits", or run a saved-credit recheck with "Also check MusicBrainz" selected — to look up composer / lyricist / arranger candidates. Search strings derived from the artist name and track title are sent to MusicBrainz. During Japanese-language rechecks, credits containing both romanized and Japanese names can also trigger an artist search sending only the Japanese person name to verify the reading. No cookies or YouTube credentials are sent, and requests do not pass through any developer server. When the extension proxies same-origin requests from a YouTube tab, the browser may attach YouTube cookies or an authorization header for YouTube only. These credentials are never sent to the developer or any third party and are not stored by the extension.

Uninstalling the extension removes the data it stores inside the browser. Downloaded JSON backup files are not removed and must be managed separately by the user.
