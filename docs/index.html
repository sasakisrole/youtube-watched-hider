履歴の使い方

よく聴く音楽も、振り返れる。

Topic チャンネルなどの履歴から、アーティスト別のランキングを表示します。

分析の「合計時間」は動画の長さの合計です。実際に聴いた時間ではありません。

詳しい使い方を読む
  1. 01

    いつもどおり、動画を観る

    再生の終了や一覧の視聴進捗などから記録します。視聴済みとみなす進捗の割合は、設定で調整できます。

  2. 02

    次の一覧では、まだ観ていない動画を探す

    記録された動画を一覧から隠します。検索結果だけは残す、といったページ別の設定もできます。

  3. 03

    また観たいときは、OFF で戻せる

    拡張機能のアイコンから非表示を OFF にできます。消さずに残したい場合は、薄く表示することもできます。

導入前に

自分の使い方に、
合うか確かめる。

  • パソコンの Chrome 向けです。ブラウザーで開く YouTube が対象です。スマートフォンの YouTube アプリでは使えません。
  • 記録・検出した動画を隠します。入れるだけで、過去の視聴履歴がすべて自動で揃うわけではありません。判定と対象ページ
  • YouTube の表示に合わせて動きます。YouTube 側の表示変更などで、検出できない場合もあります。

保存と通信

履歴は、
ブラウザー内に保存。

視聴履歴と設定はブラウザー内に保存します。保存した履歴を開発者のサーバーへ送ることはありません。

動画情報の取得や、自分で実行する高評価の同期などで YouTube と通信します。

クレジットの補完・再点検を自分で実行した場合は、曲名・アーティスト名などを使って MusicBrainz に問い合わせることがあります。
